# Bank-churn-prediction
Предсказание оттока клиентов банка (Catboost)

## Цель проекта
Построить модель классификации для анализа оттока клиентов с использованием библиотеки CatBoost

## Данные
- Kaggle: https://www.kaggle.com/datasets/gauravtopre/bank-customer-churn-dataset
- 10 000 клиентов
- 3 страны (Германия, Франция, Испания)
- 4 банковских продукта

## Переменные
- credit_score — кредитный рейтинг
- country — страна (категориальные)
- gender — пол клиента (категориальные)
- age — возраст
- tenure — срок обслуживания клиента в банке
- balance — баланс на счете
- products_number — количество используемых продуктов
- credit_card — есть ли кредитная карта (1/0)
- active_member — активный ли клиент (1/0)
- estimated_salary — оценочная зарплата
- churn — целевая переменная: 1, если клиент покинул банк за определенный период, и 0, если нет
- customer_id - не используется

## Методы
1. Разведочный анализ данных (EDA — Exploratory Data Analysis)
2. Разбиение данных на train/validation/test (60/20/20)
3. Применение CatBoost
4. Подбор порога классификации на validation-выборке. Порог подобран на validation, итоговые метрики посчитаны на test.

## Результаты
1. Наиболее важные признаки по CatBoost: возраст (19,87%), количество используемых продуктов (19,65%) и баланс (13,04%)
2. Метрика ROC-AUC составляет 0.860. Модель заметно лучше случайного угадывания (0,5)
3. Модель находит 62% клиентов (Recall = 0,62), которые действительно уходят.
4. Из клиентов, которых модель назвала уходящими, 64% действительно ушли (Precision = 0,64).
5. f1-score составляет 0,63
